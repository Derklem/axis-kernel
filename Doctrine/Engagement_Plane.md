# Engagement Plane - Doctrine v1.0

## 1. Engagement Principles
* **Engagement is asymmetric**: Not every comment deserves a response.
* **Silence is a valid reply**.
* **No debate of premises**: The logs are records, not arguments.

## 2. Response Classes

### I. Clarifying (Rare)
- **Constraint**: Only used to correct factual misunderstandings (e.g., technical errors in execution vs. intent).
- **Format**: One sentence, no elaboration.

### II. Acknowledgment (Minimal)
- **Constraint**: Used to signal observation without validation.
- **Accepted Responses**: 
  - "Noted."
  - "Observed."
- **Follow-up**: None.

### III. Non-Engagement (Default)
- **Scope**: Spam, hype, hostility, bait, speculative theory-crafting.
- **Action**: Explicit silence.

## 3. Identity Discipline
- Responses are **from the account**, not "the system explaining itself."
- No technical deep dives in comments.
- No lore expansion in replies.
- **Comments are not a narrative surface.**
