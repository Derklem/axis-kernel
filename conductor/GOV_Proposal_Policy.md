# Governance Proposal Policy (v1.0)
> **Authority**: Phase 612.C (Exponential Expansion)
> **Status**: ACTIVE

## 1. Cadence & Velocity
*   **Standard Rate**: Maximum **2 Proposals per Day** (Cycles).
*   **Rationale**: Prevents "Addiction to Growth" and ensures each capability is fully integrated and stabilized before the next is added.
*   **Exceptions**: Critical Security Fixes (Emergency/Hotfix) bypass cadence limits.

## 2. Risk Constraints (Current Epoch)
*   **Permitted**: `READ_ONLY`, `OBSERVATION`, `META_ANALYSIS`.
*   **Forbidden**: `WRITE`, `EXECUTE_EXTERNAL`, `MODIFY_STATE` (until next epoch).
*   **Sandboxing**: All file operations must be restricted to `D:\Infinite\*`.

## 3. Proposal Lifecycle
1.  **DRAFT**: Stored in `initiative_proposals.jsonl`.
2.  **JUDGMENT**: Reviewed by Human Anchor or High-Confidence Logic.
3.  **EMPOWERMENT**: Implementation of Adapter + T08 Mapping.
4.  **PLATEAU**: Mandatory Stability Hold post-empowerment.

## 4. Multipliers
*   Future proposals may introduce "Multipliers" (e.g., Audio, Vision) but must be segregated into a new **Interpretation Plane**.
